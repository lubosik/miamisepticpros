<h2 id="what-is">What is a septic site evaluation?</h2>

<p>Septic site evaluation is critical preliminary assessment conducted to determine whether property is suitable for installation of onsite sewage treatment and disposal system (OSTDS). Evaluation involves comprehensive examination of soil characteristics, environmental conditions, and property features to ensure septic system can function safely and effectively while protecting groundwater and surface waters from contamination.</p>

<strong>Purpose of site evaluation:</strong>
<ul>
<li>Determine site suitability for septic system</li>
<li>Assess soil characteristics and percolation rate</li>
<li>Evaluate environmental conditions and constraints</li>
<li>Identify property features affecting system design</li>
<li>Determine appropriate system type and size</li>
<li>Ensure compliance with regulatory requirements</li>
</ul>

<strong>Why evaluation is required:</strong>
<ul>
<li>Mandatory before septic system can be permitted</li>
<li>Florida regulations require professional evaluation</li>
<li>Ensures proper system design and placement</li>
<li>Protects groundwater and environmental resources</li>
<li>Required for permit application</li>
<li>Foundation for system design decisions</li>
</ul>

<strong>Who performs evaluation:</strong>
<ul>
<li>Licensed engineer</li>
<li>Qualified professional</li>
<li>Must meet state licensing requirements</li>
<li>Professional credentials verified</li>
<li>Experience in septic system evaluation</li>
</ul>

<p>Site evaluation provides foundation for septic system design and installation <a href="https://www.floridahealth.gov/environmental-health/onsite-sewage/disposal-system-permits/index.html" target="_blank" rel="noopener noreferrer">(Florida DOH)</a>. Professional evaluation ensures accurate assessment and proper documentation for permit application.</p>

<h2 id="process">Evaluation process step-by-step</h2>

<p>Site evaluation follows structured process ensuring comprehensive assessment:</p>

<strong>Step 1: Initial property inspection</strong>
<p>Qualified professional conducts on-site inspection examining property layout, identifying structures and features, assessing topography and slope, locating water features, and gathering preliminary information. Inspection provides initial assessment of property conditions.</p>

<strong>Step 2: Property feature identification</strong>
<p>Identify and document property boundaries, nearby property lines, existing structures and buildings, water wells on or near property, surface water bodies, wetlands, and environmental features. Feature identification determines constraints affecting system placement.</p>

<strong>Step 3: Soil percolation testing</strong>
<p>Conduct soil percolation testing at representative locations where absorption field will be installed. Testing measures how quickly water flows through native soil. Percolation rate directly determines required absorption field size. Multiple test locations may be needed.</p>

<strong>Step 4: Soil analysis</strong>
<p>Analyze soil composition and type including soil texture, structure, and characteristics. Different soil types have different percolation rates. Clay soils percolate slowly requiring larger fields. Sandy soils percolate quickly but may not provide adequate treatment. Soil analysis determines percolation capacity.</p>

<strong>Step 5: Groundwater depth assessment</strong>
<p>Determine depth to groundwater at site. Shallow groundwater requires enhanced treatment and different system configurations. Deep groundwater may allow conventional designs but requires verification of adequate separation distances. Groundwater depth affects system type selection.</p>

<strong>Step 6: Setback distance verification</strong>
<p>Verify required setback distances from property lines, water wells, surface water bodies, structures, and other features. Setback requirements must be met for system placement. Verification ensures compliance with regulatory requirements.</p>

<strong>Step 7: Environmental factor assessment</strong>
<p>Assess environmental factors including proximity to surface waters, environmental sensitivity, groundwater protection needs, and potential contamination risks. Environmental assessment determines system type requirements and treatment specifications.</p>

<strong>Step 8: Documentation and reporting</strong>
<p>Complete DH4015 form documenting all findings including soil characteristics, property features, environmental conditions, percolation test results, and evaluation conclusions. Documentation becomes part of official permit application. Report provides basis for system design.</p>

<p>Following proper evaluation process ensures comprehensive assessment and proper documentation <a href="https://www.epa.gov/septic" target="_blank" rel="noopener noreferrer">(EPA)</a>. Professional evaluation provides foundation for septic system design and installation.</p>

Simple residential evaluations cost $500-$1,000. Standard evaluations cost $800-$1,500. Complex commercial evaluations cost $1,200-$2,500. <h3>What is a septic site evaluation?</h3>

<p>Septic site evaluation is critical preliminary assessment conducted to determine whether property is suitable for installation of onsite sewage treatment and disposal system. Evaluation involves comprehensive examination of soil characteristics, environmental conditions, and property features to ensure septic system can function safely and effectively while protecting groundwater and surface waters. Evaluation is mandatory before septic system can be permitted and provides foundation for system design.</p>

<h3>What does a site evaluation include?</h3>

<p>Site evaluation includes property inspection and assessment, soil percolation testing to measure absorption capacity, groundwater depth evaluation, property feature identification including boundaries and structures, water well and surface water location, environmental factor assessment, and comprehensive documentation using DH4015 form. Evaluation assesses all factors affecting septic system design and installation. Professional evaluation provides complete assessment meeting all requirements.</p>

<h3>Who can perform a septic site evaluation?</h3>

<p>Site evaluations must be performed by licensed engineer or other qualified professional as mandated by Florida regulations. Licensed engineers and qualified professionals must meet state licensing requirements and have experience in septic system evaluation. Professional credentials must be verified. Professional evaluation ensures standardized assessment and proper documentation for permit application.</p>

<h3>How long does site evaluation take?</h3>

<p>Site evaluation typically takes 1-2 weeks from initial inspection through completion of documentation. Property inspection takes 1-2 days. Soil testing takes 2-3 days including test preparation and results. Documentation and report preparation takes 3-5 days. Total timeline depends on property complexity and professional workload. <h3>What happens after site evaluation?</h3>

<p>After site evaluation, results are used for septic system design including system type selection, placement location, sizing based on percolation rate, and treatment specifications. Evaluation results become part of permit application documentation. Professional engineer uses evaluation results to design system meeting all requirements. Evaluation provides foundation for complete system design and installation process.</p>

<h3>Can a property fail site evaluation?</h3>

<p>Site evaluation may determine property is not suitable for septic system installation if soil conditions are inadequate, groundwater is too shallow, setbacks cannot be met, environmental constraints prevent installation, or other factors make system installation unfeasible. In such cases, alternatives may be available including advanced treatment systems, holding tanks, or connection to municipal sewer if available. Professional evaluation identifies feasibility and available options.</p>
