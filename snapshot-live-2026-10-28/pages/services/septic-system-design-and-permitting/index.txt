<h2 id="types">Septic system types (Type 2, 3, 4)</h2>

<p>Miami-Dade County Ordinance 22-83 requires specific system types for new installations <a href="https://www.miamidade.gov/water/sewer/septic-systems" target="_blank" rel="noopener noreferrer">(Miami-Dade County)</a>:</p>

<strong>Type 2 Systems (Secondary Treatment):</strong>
<ul>
<li>Minimum standard for new residential installations</li>
<li>Suitable for single-family homes or duplexes</li>
<li>Less than 500 gallons per day capacity</li>
<li>Must be 1,000 feet or more from surface water</li>
<li>Meets secondary treatment standards</li>
<li>Most common for residential applications</li>
</ul>

<strong>Type 3 Systems (Advanced Secondary Treatment):</strong>
<ul>
<li>Required for multifamily residential properties</li>
<li>Properties not exceeding 1,000 gallons per day</li>
<li>Must be 1,000 feet or more from surface water</li>
<li>Enhanced treatment capability</li>
<li>Higher treatment standards than Type 2</li>
<li>Suitable for higher-density applications</li>
</ul>

<strong>Type 4 Systems (Nutrient Reduction):</strong>
<ul>
<li>Highest treatment standard available</li>
<li>Meets Florida Keys Nutrient Reduction Treatment Standards</li>
<li>Required when Type 2 or 3 criteria not met</li>
<li>Environmentally sensitive area applications</li>
<li>Most comprehensive treatment</li>
<li>Highest cost but best environmental protection</li>
</ul>

<strong>Type 1 Systems (Prohibited):</strong>
<ul>
<li>Conventional septic systems no longer allowed</li>
<li>Prohibited for all new installations</li>
<li>Prohibited for complete system replacements</li>
<li>Existing Type 1 systems may continue operating</li>
<li>Grandfathered systems remain in place</li>
</ul>

<p>System type selection depends on property use, sewage flow rate, proximity to surface water, and environmental sensitivity. Professional engineers determine appropriate system type based on site-specific conditions and regulations.</p>

<h2 id="design-process">Design process step-by-step</h2>

<p>Professional design process ensures proper system function and compliance:</p>

<strong>Step 1: Site evaluation and feasibility</strong>
<p>Comprehensive site evaluation assesses soil conditions, groundwater elevation, topography, proximity to water resources, and site suitability for onsite sewage treatment. Evaluation determines if site meets minimum requirements and identifies constraints affecting design.</p>

<strong>Step 2: Soil testing and characterization</strong>
<p>Detailed soil investigation includes soil permeability testing, soil boring data collection, seasonal high water table elevation determination, and soil suitability assessment. Soil data is essential for drainfield sizing and elevation requirements.</p>

<strong>Step 3: System type selection</strong>
<p>Based on evaluation results, engineer selects appropriate system type considering land use, projected sewage flow, proximity to surface water, and environmental sensitivity. System type affects treatment requirements and costs significantly.</p>

<strong>Step 4: Engineering design calculations</strong>
<p>Detailed calculations determine tank sizing, drainfield area requirements, treatment component specifications, and system capacity based on selected system type. Engineering ensures proper system sizing for expected usage.</p>

<strong>Step 5: Site plan creation</strong>
<p>Scaled site plan shows all structures, property lines, setback distances, system location relative to surface water, well locations if applicable, and all required measurements. Site plan demonstrates compliance with setback requirements.</p>

<strong>Step 6: Design specification development</strong>
<p>Complete design specifications include tank specifications, drainfield design details, treatment component requirements, installation specifications, and compliance with Chapter 62-6 requirements. Specifications guide installation and ensure compliance.</p>

<strong>Step 7: Compliance verification</strong>
<p>Final review verifies design meets all Miami-Dade County requirements including system type, setbacks, elevation, site conditions, and regulatory standards. Compliance verification ensures permit approval.</p>

<p>Following proper design process ensures system function, environmental protection, and regulatory compliance. Professional engineers manage entire design process meeting all requirements.</p>

<h3>What permits do you need for a septic system?</h3>

<p>All new or replacement septic systems require prior written approval from Miami-Dade DERM Director before construction. <p>Miami-Dade County Ordinance 22-83 requires Type 2, Type 3, or Type 4 systems for new installations (Type 1 prohibited). <h3>What happens if my permit is denied?</h3>
